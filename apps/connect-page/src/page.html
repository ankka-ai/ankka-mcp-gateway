ChatGPT
  1. Open Plugins in ChatGPT, select +, then Add custom MCP server.
  2. Enter a name for your team’s gateway and paste the MCP server URL above under Connection. Use OAuth authentication.
  3. Review the connection notice and select Create as a plugin. Install the plugin and complete sign-in with your approved account.
  4. Type @ in your chat and select the plugin to use its tools.

Your workspace permissions determine whether you can add custom MCP servers. Your workspace administrator may need to add this gateway for you. ChatGPT setup guide ↗

ClaudeAdd to Claude
  1. Open Customize → Connectors, select + Add, then Add custom connector.
  2. Give the connector a name and paste the MCP server URL above.
  3. Connect and complete the sign-in flow. Enable the connector in your conversation.

Your organization may require an administrator to add custom connectors. Claude setup guide ↗

Google Gemini
  1. Open Gemini on the web and go to Settings → Connected Apps. If needed, open Personal Intelligence first.
  2. Under Custom apps, select Add a custom app and paste the MCP server URL above.
  3. Select Next and follow the sign-in instructions. Type @ in your chat to select the connected app.

Google currently limits custom apps to personal accounts for adults in the US, in English, with Keep Activity on. Your gateway administrator may also need to enable Gemini sign-in. Gemini setup guide ↗

Another MCP client
  1. Add a remote MCP server with the URL above.
  2. Choose Streamable HTTP if your client asks for a transport.
  3. Complete the browser sign-in when your client prompts you.

Your client needs support for remote MCP servers and OAuth sign-in.

Can’t connect? Check that you’re signing in with your approved account, or ask your gateway administrator for access.
